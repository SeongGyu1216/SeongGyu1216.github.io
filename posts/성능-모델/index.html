성능 데이터 모델링이란
2026-05-27 09:09:59 KST · 2 min
    1. 성능 데이터 모델링
    • 성능 데이터 모델링이란?
      • 자료 기준 정의:
        • 데이터베이스 성능 향상을 목적으로 수행하는 모델링 작업
      • 핵심:
        • “DB가 돌아가게 만드는 것”이 아니라
        • “빠르고 안정적으로 동작하게 만드는 것”
    • 왜 중요한가?
      • 자료 핵심 설명:
        • 쿼리 1개가 내부적으로 매우 많은 작업을 수행할 수 있다.
        • 자주 실행되는 비효율 쿼리는 DB 전체 성능에 영향 가능
        • 구조 자체가 잘못되면:
          • 원하는 조회가 어려워지고
          • 불필요한 JOIN 증가
          • 중복 접근 증가
          • 성능 저하 발생
    • 쉬운 말로 다시 말하면
      • SQL 속도 문제는:
        • SQL 문법만의 문제가 아니다.
      • 테이블 구조 자체가:
        • 조회 패턴에 안 맞으면
        • 아무리 SQL을 고쳐도 한계가 생긴다.
      • 예:
        • 주문 조회를 자주 하는데
        • 고객 정보가 지나치게 분리되어 있으면
        • JOIN이 반복 발생
        • → 조회 비용 증가
